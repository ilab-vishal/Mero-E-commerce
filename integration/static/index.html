Webhook Configuration Guide

Why do I need a Public URL?

Development (Your PC): Shopify is in the cloud, but this app is on your computer. Ngrok creates a bridge so Shopify can talk to you.

Production (Real Domain): If you deploy this app to a server (like AWS/Heroku) with a real domain (e.g., https://api.myapp.com), you DO NOT need Ngrok. Use your real domain instead.

Get/Setup Ngrok Free
1

Start Ngrok

Run the command ngrok http 8000 in your terminal and copy the "Forwarding" URL (e.g., https://xyz.ngrok-free.app).

2

Open Shopify Webhooks

Go to Settings > Notifications > Webhooks in your Shopify Admin and click Create webhook.

3

Enter Details

Event: Product creation
Format: JSON
URL:
https://<YOUR_NGROK>/webhooks/shopify/products/create

REPEAT this step for Product update and Product deletion events.
